# Web 前端规范

## 按钮组间距

- 弹窗底部、表单操作区、工具栏和列表操作区中的相邻按钮，必须通过操作容器的 `flex` / `grid` 和显式 `gap` 保持间距，不依赖组件库默认的 `margin` 或模板空白。
- 常规按钮组默认使用 `gap: 0.75rem`，紧凑操作区可使用 `gap: 0.5rem`；已有操作容器保持项目现有间距。
- 项目全局样式已将 `.el-button + .el-button` 的 `margin-left` 设为 `0`，因此弹窗 `footer` 中的多个按钮也必须包在设置了 `gap` 的操作容器内。
- 按钮组在窄屏下需要换行时使用 `flex-wrap: wrap`，保证横向和纵向均有间距。新增或修改按钮区后，实际检查桌面和窄屏布局，确认按钮不相贴、不重叠且可点击。

## 滚动条

- 页面内列表、详情和弹窗等需要滚动的内容区域，统一使用 Element Plus 的 `ElScrollbar`（模板中使用 `<el-scrollbar>`）。
- 为滚动区域设置明确的 `height`、`max-height` 或受约束的容器高度；弹窗高度需扣除标题和内边距，并适配窄屏与小高度视口。
- 使用 `ElScrollbar` 时，避免外层容器同时设置 `overflow: auto` 或 `overflow: scroll`，防止出现双重滚动条。弹窗样式覆盖应限定到当前弹窗。
- 为内容预留右侧间距，避免滚动条遮挡文字；需要键盘滚动时，设置 `:tabindex="0"` 并提供清晰的 `aria-label`。
